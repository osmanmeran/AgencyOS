QUICK REFERENCE: Performance Optimization Tips
================================================================================

1. DATE OPERATIONS
   ✗ Don't: const now = new Date().toISOString() multiple times
   ✓ Do: const now = new Date().toISOString(); // cache result

2. JSON PARSING
   ✗ Don't: Parse JSON in loops and nested function calls
   ✓ Do: Parse once, pass parsed object through functions

3. OBJECT LOOKUPS
   ✗ Don't: Build lookup maps on every request
   ✓ Do: Build once at module level, reference by key

4. ARRAY OPERATIONS
   ✗ Don't: Multiple .reduce()/.map() on same array
   ✓ Do: Single-pass loop with early exits

5. TYPE CONVERSION
   ✗ Don't: String(value) unconditionally
   ✓ Do: typeof value === 'string' ? value : String(value)
