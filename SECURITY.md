# Security Policy

## Supported Versions

Only the latest release on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Marvelops TravelPro seriously. If you discover a vulnerability, please do **NOT** open a public issue.

Instead, please send a report to the project maintainers via:

- **Email**: `security@marvelops.app` (or contact the repository owner directly via GitHub Security Advisories)

### What to Include in Your Report

Please provide:

1. Description of the vulnerability.
2. Steps to reproduce or proof-of-concept exploit.
3. Affected components (e.g. specific routes, auth middleware, tenant isolation).
4. Potential impact (e.g. privilege escalation, tenant bleed, data exposure).

### Response Process

1. **Acknowledgment**: We aim to acknowledge reports within 48 hours.
2. **Investigation**: We will verify the vulnerability and assess severity.
3. **Patch & Advisory**: A fix will be developed in a private branch, verified, and released.
4. **Credit**: Security researchers adhering to responsible disclosure will be credited in release notes.
